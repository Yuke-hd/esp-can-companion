# Architecture decision records

Each record captures one significant decision: context, the choice, consequences,
and alternatives considered. Architecture and specs own detailed current
behavior; a record explains why. Use the [ADR template](../templates/ADR.md) and
the next free number. A changed decision gets a new record superseding the old
one rather than rewriting its history.
