# Repository instructions

- For UI changes, follow [UI preview and verification](docs/development/ui-verification.md).
- Use the [scenario reference](docs/specs/ui/preview-scenarios.md) to distinguish
  available checks from planned features. Inspect rendered UI as well as test results.
- Preserve the replaceable boundaries in [module boundaries](docs/architecture/module-boundaries.md).
- Routine UI verification uses the in-app fake; see [ADR-0001](docs/decisions/0001-in-app-fake-for-ui-verification.md).
- Documentation categories and authority are explained in [docs/README.md](docs/README.md).
